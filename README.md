# CC GUI 个人任务看板

本地管理个人任务，通过 CC GUI 原生会话执行，结果由人工验收。当前版本 **0.1.31**。

## 安装

在 CC GUI 中选择“插件 → 从本地目录安装”，选择本仓库的 **ccgui-plugin/** 目录（包含 manifest.json 的那一层）。这是手写单文件 ESM 插件，不需要构建，也不必安装开发依赖。市场收录后也可一键安装。

修改后重新安装同一目录即可热重载。更新前请先结束看板任务；插件页可禁用或卸载。

## 功能与权限

支持看板、列表、甘特、父子泳道、项目共享说明、原生会话执行与返工、人工验收、任务通知、讨论结论、选区引用和历史轮次重试。

宿主能力均经 PluginContext；权限在 ccgui-plugin/manifest.json 声明。任务和设置保存在本机插件隔离存储。附件保留原路径，AI 工具的文件与网络能力由宿主控制。

完整功能和使用限制见 [插件使用说明](ccgui-plugin/README.md)，规范核查见 [审计报告](docs/ccgui-plugin-compliance-audit.zh-CN.md)。

## 开发验证

开发依赖仅用于测试，不是插件运行依赖。以下命令适用于 macOS / Linux：

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm test
```

测试脚本将 CCGUI_HOST_PACKAGE 指向本仓库 package.json，独立加载 React 和 jsdom，无需同级宿主开发仓库。Windows 可先将该环境变量设为本仓库 package.json 的绝对路径，再执行 node --test ccgui-plugin-tests/*.test.mjs。

测试使用假的会话接口，不调用真实模型。此仓库没有模板构建步骤，安装目录始终是 ccgui-plugin/。

## 目录

- ccgui-plugin/：可直接安装的插件。
- ccgui-plugin-tests/：控制器与 React 组件测试。
- docs/：开发、验收及规范核查记录，历史版本记录保留原项目中的路径供追溯。

本插件参考 Multica 的任务流程，未提取其原版界面或业务代码。


## 市场发布与许可证

本项目采用 [MIT 许可证](LICENSE)。公开 Release 由 [.github/workflows/release.yml](.github/workflows/release.yml) 从版本标签的源码打包，不手工上传本地产物。

根 manifest.json 与 ccgui-plugin/manifest.json 保持一致；标签必须等于 version 且不加 v 前缀。Release 附件为 main.js、manifest.json、styles.css 和 checksums.txt。组件样式内嵌 main.js，styles.css 只说明这一交付形式。

手动下载 Release 时，将三个插件附件放在同一目录，通过 CC GUI 本地安装入口选择该目录。市场初次上架还需索引仓库维护者人工审核合并。


## 0.1.24 移植功能

- 任务详情与预览内查找需求、验收标准、评论、反馈，支持匹配定位与折叠讨论展开。
- 手动登记交付物并关联评论和运行；仅关联本地路径，不保存历史文件内容。
- 执行与验收时间线串联已有记录，不补造旧数据缺失的事件。
- 项目公共链接和文件清单按工作区隔离，后续运行保存独立清单快照。
- 编辑保存失败后可读取最新版本逐字段对照，保留本地输入与最新运行、评论记录。
- 手动选择实现或审查步骤，预览后确认执行；步骤配置只覆盖当轮，结束后仍需人工验收。

六项功能在本次开发中共同形成 0.1.24 候选版，未分别发布 0.1.19–0.1.23。更新前先备份任务文档；回滚旧插件前也应备份当前数据，旧版项目说明编辑可能移除新增资源字段。


## 0.1.25 第二批补强

带项目说明或公共资源的普通卡片执行入口先展开上下文再执行。编辑冲突区分当前任务未变与字段变化，支持明确重新载入；有未保存输入时取消须确认放弃。新增二次冲突、文件选择取消与资源移除回归测试。


## 0.1.26 手动分步交接补强

详情提供“交给审查”快捷入口，选择后仍需预览并确认。实现和审查切换保留各自未提交配置；实际启动时保存对应步骤配置。运行历史和时间线支持前序运行跳转，交接时登记的成果清单保存为关联快照，历史重试保留同一来源。审查反馈复用原有人工返工流程。


## 0.1.27 Agent 协作候选版

新增Agent成员配置、任务指派、定向提及、共享文本方法库、已捕获事件日志和人工确认的小队派活。通过宿主已安装CLI执行，不复制登录凭据；SDK最低0.3.23，新增 `runtime.events.read` 只读权限，用于采集本插件运行事件。

小队先运行队长，用户从原生会话核对建议后手工登记提案，再预览并确认派给一个成员，不自动解析模型输出。日志保留时间戳和宿主公开的结构化字段，不保证完整工具输入输出，容量和写入失败会造成缺口。方法库不安装原生Skill包。更新和降级前均备份完整任务文档。

完整路线及109项测试结果见 [Agent开发与验收记录](docs/ccgui-agent-development-plan.zh-CN.md)。当前源码候选未自动安装到正式客户端。


## 0.1.28 配置入口调整

首页右下角新增“任务面板配置”，统一管理共享方法库、手动协调小队、Agent 成员、视图偏好、项目共享说明与公共资源。首页保留任务布局、排序、筛选和批量操作。

真实 CLI 安装验收见 [验收记录](docs/ccgui-real-cli-acceptance.zh-CN.md)。


## 0.1.29 配置页分类导航

采用左侧分类导航，Agent、小队和方法库使用列表与编辑表单双栏布局，支持窄窗口适配。切换分类保留当前页未保存草稿；保存仍沿用条件写入，不改变已有配置及执行流程。

## 0.1.31 任务详情工作台

详情采用文档工作台布局，需求与验收、讨论、执行记录分标签展示，任务属性与关联位于右侧；窄预览自动改为单栏。置顶验收区提供本轮会话和人工验收入口，跨标签搜索与引用定位保留，切换标签不丢失评论草稿。

115 项自动化测试通过，安装与回退方式见 [详情工作台验收记录](docs/ccgui-detail-workbench-validation.zh-CN.md)。
