# 0.1.3 验收反馈与返工验证

日期：2026-10-29（Asia/Shanghai）。插件：`personal-task-board` 0.1.3。本机 CC GUI 1.1.8。

## 使用流程

1. 在待验收任务中点击“验收不通过”。
2. 在独立的“验收反馈”页填写具体的未通过项、实际偏差和修正要求。
3. 点击“保存反馈”。任务回到待办，显示“验收未通过 · 待修正”；此时不会自动执行。
4. 点击“执行修正”。新会话携带原需求、验收标准、原附件路径与全部尚未通过的反馈，逐条处理并报告验证结果。
5. 运行结束后再次进入待验收。仍有偏差时可再次反馈；全部满足后点击“验收通过”，相关反馈才标记为“已通过复验”。

待修正任务可以“补充反馈”。反馈、时间及对应执行结果入口均保留在任务卡片的“验收反馈”中；“执行记录”保留原会话与修正会话，并标识对应的验收决定。“编辑”只修改原始任务清单，不改写已有反馈。

## 实现边界

当前 SDK 的 `sessions.startRun` 创建新会话，未提供向既有原生会话追加轮次的参数。插件明确告知用户这一点：本次修正依靠原任务、未通过反馈和现有工作区进行，新旧会话均从同一任务追溯；不宣称继承旧会话的完整模型上下文。

本轮真实验证使用文字反馈和无文件修改的测试请求。错误、重复返工及过期状态等通过自动化模拟验证，未人为破坏实际任务文件。没有改动 CC GUI 主程序或增加插件权限。
