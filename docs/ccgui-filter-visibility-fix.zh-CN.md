# 任务可见性与视图对齐修复

日期：2026-10-29。版本：0.1.8。

## 根因

用户任务“测试”已保存为待办，但项目为空，当前视图筛选项目为“个人面板验收”，因此任务被筛掉。执行入口位于任务卡片，卡片不可见后也无法从看板启动。不是任务数据丢失。

“显示子任务”标签复用了 `.ptb-actions`，额外带有上边距；普通标签又采用文字基线排列，导致同一行标签和控件不齐。

## 修复

- 新建任务沿用当前工作区、项目、标签及优先级筛选上下文。
- 保存成功后，只调整会隐藏保存任务的筛选，并展开其所在状态列。取消不改变视图。
- 增加清除筛选入口、可见/全部计数，以及全被筛选隐藏时的提示。
- 视图标签统一 inline-flex、垂直居中，复选框标签去掉额外上边距；下拉框、输入和按钮等高。

## 验证

- Node 控制器与真实 React/jsdom 测试 **52 项通过**。
- 回归复现：项目、优先级、搜索、状态及隐藏子任务组合会隐藏任务；保存后恢复可见，保留仍匹配的筛选与排序，并展开待办列。
- 组件流程：当前项目下新建任务默认继承项目；手动改为其他项目后保存仍可见，开始执行按钮可用，点击可调用模拟原生会话执行接口。
- 样式检查：各标签 inline-flex、align-items:center、margin-top:0，保持 36px 控件高度。
- 正式客户端已热更新 0.1.8。清除项目筛选后，“测试”已在待办显示，“开始执行”可点击；实机截图核对工具栏文字及复选框对齐。
- 磁盘核对用户任务记录完整未改动，本次没有替用户启动该任务。插件未隔离、无加载错误，安装文件与源码一致。
