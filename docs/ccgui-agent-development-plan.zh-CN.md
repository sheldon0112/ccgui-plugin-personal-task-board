## 第一阶段实现

Agent 成员入口可新增与编辑、归档；模型和渠道来自宿主目录。任务详情支持“我”或具体Agent负责人，指派只保存，不自动执行。启动使用身份配置与指令，历史保存独立Agent快照；手动步骤配置覆盖当轮模型时，快照记录实际执行配置。已指派身份的分步预览包含相同Agent指令。归档不删除历史，历史重试使用当轮快照。

101项自动化测试通过，0失败、0跳过；包含真实React的成员保存、指派、步骤预览及发送一致性验证。语法与差异检查通过。代码审查发现的预览遗漏已修复并加入回归测试。未调用真实模型、未改正式任务、未自动安装或发布。

## 数据兼容限制

任务文档新增可选agents与assigneeId、运行agentSnapshot。旧数据默认无Agent。降级至0.1.26后再次保存任务可能移除根agents字段，因此尝试新功能前必须备份任务文档；不要直接对新增身份的数据使用旧版保存。

自动结果评论、自由选择机器、多真人同步、自动派活和完整工具回放仍不在此候选版范围。后续阶段进度以末尾0.1.27验收记录为准。


## 0.1.27 完整路线实现与验证

### 功能

- 定向提及通过下拉框选择稳定 Agent ID，支持同名及改名。回复历史运行时继承当轮 Agent 身份；未知显式 @ 不继承；/note 与 @all 不启动。改变评论目标不改变任务负责人。
- 方法库支持创建、编辑、停用和多 Agent 绑定。内容随执行注入并保存独立快照；历史重试使用旧快照，停用不删除既有绑定。此为文本方法库，不是原生技能包安装器。
- 日志通过 SDK registerTurnHooks/onRuntimeEvent 读取命令开始/结束、工具结束、文件变化等已规范化事件。按本插件已知运行ID、引擎及工作区过滤，去重并按时间查看；保存未知退出码null，不推断成功。订阅在停用时清理。宿主不支持时显示未采集。
- 每轮最多2000条日志，单字段最多16000字符；启动早期缓冲最多100条。写入失败上报错误，重启、断连、缓冲或容量限制可能造成缺失，不能声称完整审计日志。日志查看不会重放执行命令。
- Squad保存队长、Agent成员与规则；队长运行只提出建议。用户打开原生会话核对建议后，选择成员并填写说明登记提案。确认页展示实际配置和完整上下文，确认后启动一名成员。每次队长评估选择一个提案执行，其他提案在来源运行变化后需重新评估。无自动派活、无自动并发、无人类账户同步。
- 派活提案仅接受本任务当前已结束的队长运行与有效小队成员；单次条件写入认领提案，防止重复确认；失败历史重试保留小队来源。执行结束仍需人工验收。

### 验证结果

109项自动化测试全部通过，0失败、0跳过。控制器覆盖ID路由、归档目标、方法快照、历史重试、队长来源、成员范围、重复确认、保存失败、日志启动早期事件、外部事件隔离、去重、null退出码、重载、订阅回收及损坏提案保护。

真实React/jsdom完整流程：加载方法与绑定 → 定向提及成员执行 → 结束待验收 → 预览队长协调并取消 → 再次确认队长执行 → 手工登记提案 → 成员派活预览 → 确认执行 → 结束仍待验收。两种小队预览均与实际发送提示词逐字一致。另验证方法编辑与停用、保留既有绑定、管理区限高滚动。

代码审查发现并修复：小队历史重试丢来源、损坏提案载入、未知显式提及误路由、确认上下文遗漏、日志权限遗漏及管理区滚动。未发现剩余阻断问题。

### 交付与实际验证边界

候选版0.1.27，要求SDK >=0.3.23，新增runtime.events.read权限。没有调用真实模型、没有自动安装或修改正式任务。正式CC GUI仍为0.1.26。完整路线结论基于隔离模拟宿主与真实React交互，不等同于真实CLI端到端验收；各引擎的事件覆盖率、真实队长输出质量与文件改动需另行验收。

安装前备份完整任务文档。新增agents/methods/squads根字段和提案/运行快照；降级旧版保存可能丢失新增根集合，不可只回滚插件而忽略数据备份。
