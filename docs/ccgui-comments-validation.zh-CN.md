# 任务评论与 Agent 触发验收

日期：2026-10-29。插件版本：0.1.5。客户端：CC GUI 1.1.8。

## 原项目规则与个人插件适配

依据 `apps/docs/content/docs/mentioning-agents.zh.mdx:38`：回复智能体评论交给该智能体，已有智能体参与的讨论沿用路由；`/note` 仅记录，显式提及覆盖默认路由。

插件每个任务使用所选引擎、模型和工作区作为 Agent。没有团队负责人路由，普通顶层评论只保存；`@Agent`、回复 Agent 结果条目、回复已触发 Agent 的讨论，会启动处理。输入前显示预览。评论可附文件。

评论独立追加到任务，不改原需求与验收标准。每次触发建立原生会话和输入快照，以选中评论为本轮重点；历史讨论作为背景，保留历史会话标识。只将本轮重点评论关联为已处理，未处理的新评论会阻止直接验收通过。

## SDK 边界

- SDK 不提供原生聊天完整回复读取。Agent 条目是持久运行记录对应的状态与结果入口，未伪造 AI 回复；完整文本在原生会话中查看。
- 不支持对运行中会话插话。忙碌或启动失败时，评论已保存并提示尚未交付，之后手动点击“交给 Agent 处理”。没有引入自动队列。
- 历史会话标识不会自动变成新会话的完整聊天文本；新一轮拿到原需求、讨论和当前重点，旧完整输出继续保留在原会话。
- 未新增权限、数据库或后端；附件仍记录本地文件路径。
