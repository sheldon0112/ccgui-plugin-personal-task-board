# 0.1.1 控件样式与附件 UI 验收

日期：2026-10-28，Asia/Shanghai。环境：macOS，CC GUI 1.1.8。插件版本：0.1.1。

## 本轮范围

- “全部工作区”与搜索框在同一水平线上，均为 36px 高。
- 新建和编辑任务的工作区、优先级、引擎、模型与列表控件统一高度、行高、内边距、边框、圆角、背景和字体；表单内控件按列宽铺满。
- 需求、验收标准分别支持宿主文件选择器，可多次选择、去重、移除及回显；每部分可以只提供附件。
- 用户确认只修改插件，先做文件选择上传。未修改客户端，未实现 Finder 拖拽到任务表单。

附件以原文件路径关联，不复制文件内容。执行时将两个分区的附件路径分别加入需求和验收标准；附件缺失或无法解析时要求模型明确报告。移除关联不删除原文件。SDK `assets:directory` 授权用于文件选择，会为选中文件的父目录保存插件资源授权。
