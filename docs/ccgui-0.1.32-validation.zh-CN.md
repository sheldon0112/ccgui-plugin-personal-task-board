# 0.1.32 遗漏功能合入验收

日期：2026-11-01。

## 范围

以已发布 0.1.31 为基线，逐项移入原 Multica 开发目录中的置顶、快捷日期和批量排期实现，未用旧 main.js 覆盖新版。保留 0.1.31 标签及 Release。

- 置顶排序在筛选后生效，保留原排序规则，不改变状态和甘特位置。
- 开始/截止日期支持本地日历快捷计算、任意日期编辑与清除。
- 看板及泳道卡片、列表、详情和侧边预览提供快捷入口；甘特标题标识置顶。
- 批量排期仅作用于当前筛选中的已选任务，先全量校验再一次落盘，失败不部分更新。
- 运行中和待核对任务禁止日期修改；置顶不触发执行。

## 验证

`pnpm check` 与 `pnpm test` 通过，共 122 项测试（原有 115 项，加恢复的 5 项逻辑与 2 项 React UI 测试）。新增测试先确认 0.1.31 缺少 dueDateShortcut 导出，再在合入后通过。

未运行真实模型、真实 CLI 或桌面实机视觉验收。宿主仓库的会话续接未提交改动不在本次插件发布范围内。权限及 SDK 要求与 0.1.31 一致。

## 安装与回退

安装来源为本仓库 ccgui-plugin/，在 CC GUI 中选择“插件 → 从本地目录安装”，选择包含 manifest.json 的目录；同 ID 覆盖并热重载。更新前备份任务文档并结束运行任务。需要回退时，从 0.1.31 Release 下载插件附件到同一目录后重新安装；插件页也可卸载。
